# Решения для синхронизации календаря с ботом

## Проблема
Веб-приложение не получает события из бота. Календарь показывает "Загрузка..." и не отображает события.

## Текущая реализация
1. Веб-приложение отправляет `tg.sendData({ action: "get_events", user_id: userId })`
2. Бот обрабатывает `web_app_data` в `handle_message`
3. Бот сохраняет события в `context.user_data['last_web_app_events']`
4. **ПРОБЛЕМА**: Бот не может отправить данные обратно в веб-приложение напрямую

## Варианты решения

### Вариант 1: HTTP API с правильной настройкой CORS (РЕКОМЕНДУЕТСЯ)
**Преимущества:**
- Простота реализации
- Надежность
- Работает для всех случаев использования
- Не требует сложной логики

**Реализация:**
1. Настроить CORS в `http_server.py` для разрешения запросов с GitHub Pages
2. Использовать прямой HTTP API вызов из веб-приложения
3. Добавить fallback на `tg.sendData` только если API недоступен

**Код для http_server.py:**
```python
from aiohttp_cors import setup as setup_cors, ResourceOptions, allow_all

# В create_app():
cors = setup_cors(app, defaults={
    "*": ResourceOptions(
        allow_credentials=True,
        expose_headers="*",
        allow_headers="*",
        allow_methods="*"
    )
})

# Для каждого route:
cors.add(app.router.add_get('/api/events', get_events_handler))
```

### Вариант 2: Использование Telegram Web App postMessage
**Преимущества:**
- Нативная интеграция с Telegram
- Не требует HTTP API

**Недостатки:**
- Telegram Web App API не поддерживает прямую отправку данных обратно
- Требует использования URL параметров (ограничение размера)

### Вариант 3: WebSocket соединение
**Преимущества:**
- Real-time синхронизация
- Двусторонняя связь

**Недостатки:**
- Сложность реализации
- Требует WebSocket сервер
- Может не работать через GitHub Pages

### Вариант 4: Периодический polling через HTTP API
**Преимущества:**
- Простота
- Надежность
- Работает везде

**Реализация:**
1. Веб-приложение периодически запрашивает события через HTTP API
2. Обновление каждые 10-30 секунд
3. При создании события в боте - автоматическое обновление в веб-приложении

## Рекомендуемое решение

**Комбинированный подход:**
1. **Основной способ**: HTTP API с CORS (для всех случаев)
2. **Fallback**: Использование localStorage + периодическое обновление
3. **Дополнительно**: Автоматическое обновление при создании события в боте

### Шаги реализации:

1. **Настроить CORS в http_server.py**
2. **Улучшить обработку ошибок в CalendarPageClient**
3. **Добавить автоматическое обновление событий**
4. **Добавить уведомление бота при создании события** (опционально)
