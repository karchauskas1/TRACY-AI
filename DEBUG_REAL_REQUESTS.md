# Отладка разницы между тестами curl и реальными запросами из Telegram

## Проблема

Во время тестов через curl все работает, но в реальном Telegram Web App видны ошибки "Load failed".

## Возможные причины

1. **Разные заголовки запросов**
   - curl отправляет простые заголовки
   - Браузер/Telegram отправляет полный набор заголовков (Origin, Referer, User-Agent)
   - CORS preflight запросы (OPTIONS)

2. **Разные форматы ответа**
   - API может возвращать разные форматы в зависимости от заголовков
   - Обработка ошибок может отличаться

3. **Кэширование**
   - Браузер кэширует старые версии
   - Telegram Web App может кэшировать старые файлы

4. **HTTPS сертификат**
   - Проблемы с сертификатом в Telegram Web App
   - Mixed Content Policy

5. **Обработка ошибок в браузере**
   - Браузер может по-другому обрабатывать ошибки сети
   - CORS ошибки могут блокироваться браузером

## Что нужно проверить

1. Реальные запросы из Telegram в логах nginx
2. Заголовки запросов (Origin, Referer, User-Agent)
3. Ответы API с реальными заголовками
4. CORS preflight запросы (OPTIONS)
5. Консоль браузера для ошибок JavaScript
