## 🔧 Требуемые исправления

### 1. Развернуть Apps Script веб-приложение

**КРИТИЧЕСКИ ВАЖНО**: Apps Script должен быть развернут с доступом **"Все"**

#### Инструкция:

1. Открой Google Sheets таблицу
2. **Расширения** → **Apps Script**
3. Убедись, что код из `feedback_apps_script.js` вставлен
4. **Развернуть** → **Новое развертывание**
5. Тип: **Веб-приложение**
6. **Выполнять от имени**: Меня
7. **У кого есть доступ**: **ВСЕ** ⚠️ (это самое важное!)
8. Нажми **Развернуть**
9. Скопируй новый URL веб-приложения
10. Обнови `FEEDBACK_APPS_SCRIPT_URL` в `.env` или `config.py`

### 2. (Опционально) Настроить маппинг в Python

Если хочешь, чтобы маппинг работал и в Python коде (для fallback на прямой API):

Добавь в `.env`:
```bash
FEEDBACK_SHEET_MAPPING=332023536:Тестировщик Катя,308477378:Тестировщик Даня
```

Но это не обязательно, так как Apps Script использует свой маппинг.
