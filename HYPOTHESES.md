# 🔍 Гипотезы о причинах ошибок

## Проблема 1: Календарь не отображает события
**Симптом**: События есть в БД, но не отображаются в веб-приложении

### Гипотеза A: user_id не передается правильно в календарь
- Календарь может получать user_id=demo или user_id=undefined
- API возвращает 400 Bad Request
- События не загружаются

### Гипотеза B: Формат ответа API не соответствует ожиданиям
- API возвращает данные в одном формате
- Календарь ожидает другой формат
- Данные не парсятся правильно

### Гипотеза C: События загружаются, но не отображаются из-за проблем с датами
- События парсятся неправильно
- Проблемы с timezone
- События фильтруются неправильно

## Проблема 2: Списки задач - "Load failed"
**Симптом**: Ошибка загрузки при открытии списков задач

### Гипотеза D: user_id=demo отправляется в API
- Веб-приложение не получает user_id из Telegram Web App
- Отправляется user_id=demo
- API возвращает 400 Bad Request: "Invalid user_id"

### Гипотеза E: Ошибка парсинга ответа API
- API возвращает данные, но формат не соответствует ожиданиям
- Ошибка при парсинге JSON
- Ошибка не обрабатывается правильно

## Проблема 3: Чат с Tracy - "Load failed"
**Симптом**: Ошибка загрузки при открытии чата

### Гипотеза F: user_id не получается правильно
- Аналогично проблеме со списками задач
- user_id=demo или user_id=undefined
- API возвращает ошибку

### Гипотеза G: Проблема с loadGreeting
- loadGreeting может вызываться с невалидным user_id
- Ошибка не обрабатывается правильно
