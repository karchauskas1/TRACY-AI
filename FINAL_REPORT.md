## 💡 Комментарии по архитектурным решениям

1. **Утренний дайджест:** Проверка каждую минуту вместо окна ±5 минут обеспечивает точную доставку, но увеличивает нагрузку. Для production можно оптимизировать, проверяя только в минуту отправки.

2. **Default Reminder:** Применяется автоматически при создании события, если не указано явное напоминание. Значение берется из настроек пользователя.

3. **API для встреч:** Добавлены endpoints для получения списка и деталей встреч. Создание события из встречи пока обрабатывается через бота (можно расширить до прямого API вызова).

4. **Темы:** Реализованы через CSS variables и класс `.dark` на `html`. Поддержка системной темы через `prefers-color-scheme`.

5. **Floating кнопка:** Удалена, доступ к функциям сохранен через меню и календарь.
