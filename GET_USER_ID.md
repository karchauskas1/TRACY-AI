# Как узнать свой Telegram User ID

## Способ 1: Через веб-приложение (самый простой)

1. Откройте веб-приложение TRACY в Telegram
2. Нажмите F12 (или ПКМ → "Inspect" / "Исследовать элемент")
3. Перейдите на вкладку **Console**
4. Введите и нажмите Enter:
   ```javascript
   JSON.parse(localStorage.getItem('telegram_user')).id
   ```
5. Это покажет ваш числовой user_id (например: `123456789`)

## Способ 2: Через бота

1. Напишите боту команду `/start`
2. Откройте логи бота (если у вас есть доступ)
3. Или используйте другого бота для получения ID (например, @userinfobot)

## Способ 3: Через консоль браузера в веб-приложении

В консоли браузера (F12) вы также можете увидеть логи вида:
```
[Calendar] Запрос к API: https://tracy-api.onrender.com/api/events?user_id=123456789
```

В этом URL число `123456789` - это и есть ваш user_id.

## Проверка API

После того, как узнаете свой user_id, откройте в браузере:
```
https://tracy-api.onrender.com/api/events?user_id=ВАШ_USER_ID
```

Где `ВАШ_USER_ID` - это число, которое вы получили выше.

**Важно:** user_id - это число, а не username (@karchauskas)!
