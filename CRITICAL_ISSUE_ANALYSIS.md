# 🔴 КРИТИЧЕСКАЯ ПРОБЛЕМА: Все разделы показывают "Load failed"

## Наблюдения:

1. Пользователь открыл приложение через Telegram
2. Все разделы показывают "Load failed":
   - Чат с Tracy
   - Списки задач
   - Обратная связь
   - Календарь (показывает "нет событий", но события есть)

## Критическая гипотеза N: Telegram WebApp не предоставляет initDataUnsafe.user

**Гипотеза N**: Когда приложение открыто через Telegram WebApp, `tg.initDataUnsafe?.user` может быть `undefined` или `null` в некоторых случаях:
- При первом открытии
- Если пользователь не авторизован в Telegram
- Если WebApp открыт не через бота

**Доказательства**:
- Пользователь открыл через Telegram, но все равно видит ошибки
- Это означает, что user_id не получается правильно

## Решение:

Нужно:
1. Проверить, что `tg.initDataUnsafe?.user` действительно доступен
2. Добавить более надежную проверку и ожидание
3. Использовать альтернативные способы получения user_id (например, через initData)
