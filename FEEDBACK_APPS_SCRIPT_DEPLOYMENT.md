# Инструкция по развертыванию Apps Script для обратной связи

## ⚠️ ВАЖНО: Настройка доступа

Если при тестировании получаешь ошибку **401 (Unauthorized)**, это означает, что веб-приложение не развернуто с правильными настройками доступа.

## Пошаговая инструкция

### 1. Открой Apps Script
1. Открой Google Sheets таблицу
2. **Расширения** → **Apps Script**

### 2. Убедись, что код обновлен
- Скопируй код из `feedback_apps_script.js`
- Вставь в редактор Apps Script
- Сохрани (Ctrl+S / Cmd+S)

### 3. Разверни веб-приложение
1. Нажми **Развернуть** → **Новое развертывание**
2. Нажми на иконку **шестеренки** (⚙️) рядом с "Тип развертывания"
3. Выбери **Веб-приложение**

### 4. Настрой параметры развертывания
**КРИТИЧЕСКИ ВАЖНО:**
- **Описание**: `TRACY Feedback Webhook v2` (или любое другое)
- **Выполнять от имени**: **Меня** (твой аккаунт)
- **У кого есть доступ**: **ВСЕ** ⚠️ (это самое важное!)

### 5. Разверни
1. Нажми **Развернуть**
2. Скопируй **URL веб-приложения** (он будет вида `https://script.google.com/macros/s/.../exec`)
3. Обнови `FEEDBACK_APPS_SCRIPT_URL` в `.env` или `config.py`

### 6. Проверь развертывание
После развертывания попробуй:
```bash
curl "https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec?action=test"
```

Если получаешь JSON ответ (не 401), значит все настроено правильно.

## Проверка текущего развертывания

1. **Развернуть** → **Управлять развертываниями**
2. Найди последнее развертывание
3. Нажми на иконку **карандаша** (✏️) для редактирования
4. Проверь, что **"У кого есть доступ"** = **"Все"**
5. Если нет - измени и **Обнови**

## Обновление кода

Если обновил код в Apps Script:
1. Сохрани изменения
2. **Развернуть** → **Управлять развертываниями**
3. Нажми **Редактировать** (карандаш) на последнем развертывании
4. Измени **Версию** на "Новая версия"
5. Нажми **Развернуть**

## Устранение проблем

### Ошибка 401
- ✅ Проверь, что "У кого есть доступ" = "Все"
- ✅ Убедись, что развертывание активно
- ✅ Попробуй создать новое развертывание

### Ошибка 403
- ✅ Проверь права доступа к таблице
- ✅ Убедись, что скрипт привязан к правильной таблице

### Ошибка 500
- ✅ Проверь логи: **Вид** → **Журнал выполнения** в Apps Script
- ✅ Убедись, что все функции правильно названы

## Тестирование

После развертывания запусти тесты:
```bash
python3 test_feedback.py
```

Все тесты должны пройти успешно.
