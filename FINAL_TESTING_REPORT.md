## 📋 Что нужно сделать пользователю

### КРИТИЧЕСКИ ВАЖНО: Развернуть Apps Script

1. Открой Google Sheets таблицу
2. **Расширения** → **Apps Script**
3. Убедись, что код из `feedback_apps_script.js` вставлен
4. **Развернуть** → **Новое развертывание**
5. Тип: **Веб-приложение**
6. **Выполнять от имени**: Меня
7. **У кого есть доступ**: **ВСЕ** ⚠️ (это самое важное!)
8. Нажми **Развернуть**
9. Скопируй новый URL веб-приложения
10. Обнови `FEEDBACK_APPS_SCRIPT_URL` в `.env` или `config.py` (если URL изменился)

### После развертывания

Запусти тесты снова:
```bash
python3 test_feedback.py
```

Все тесты должны пройти успешно.
