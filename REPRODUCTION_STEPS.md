# 📋 Инструкции для воспроизведения ошибок

## Цель:
Воспроизвести ошибки, чтобы собрать логи и понять точную причину проблем.

## Шаги:

1. Откройте веб-приложение через Telegram бота
2. Откройте консоль браузера (F12 или через меню разработчика)
3. Перейдите на вкладку "Console" (Консоль)
4. Попробуйте открыть каждый проблемный раздел:
   - Календарь (проверьте, отображаются ли события)
   - Списки задач (проверьте, появляется ли "Load failed")
   - Чат с Tracy (проверьте, появляется ли "Load failed")
5. Подождите 5-10 секунд после открытия каждого раздела
6. Нажмите кнопку "Proceed" (Продолжить) в интерфейсе отладки

## Что будет записано в логи:

- Как получается user_id (из state, Telegram WebApp, localStorage)
- Значение user_id перед отправкой запроса
- URL запроса к API
- Статус ответа API
- Сырой ответ API
- Результат парсинга JSON
- Формат данных после парсинга
- Ошибки, если они есть

## Важно:

- Не закрывайте консоль браузера во время тестирования
- Откройте все три проблемных раздела
- Подождите несколько секунд после каждого действия
