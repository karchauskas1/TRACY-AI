# Отладка API на Render.com

## Проблема

База данных создана, `DATABASE_URL` добавлен, но все еще ошибка:
```json
{"error": "Failed to get or create user"}
```

## Что нужно проверить

### Шаг 1: Проверьте логи на Render.com

1. Откройте ваш Web Service на Render.com (`tracy-api`)
2. Перейдите во вкладку **"Logs"**
3. Найдите ошибки, связанные с базой данных
4. Скопируйте последние логи и проверьте:
   - Есть ли сообщение "Используется PostgreSQL"?
   - Есть ли ошибки подключения к базе данных?
   - Есть ли ошибки при создании таблиц?

### Шаг 2: Проверьте переменные окружения

1. В Render.com перейдите в ваш Web Service
2. Откройте вкладку **"Environment"**
3. Убедитесь, что:
   - `DATABASE_URL` присутствует
   - Значение начинается с `postgresql://` (не `postgres://`)
   - Это **Internal Database URL** (не External)
   - Нет лишних пробелов или символов

### Шаг 3: Проверьте статус базы данных

1. В Render.com перейдите в ваш PostgreSQL Database
2. Убедитесь, что статус **"Available"** (зеленый)
3. Если статус другой - подождите, пока база данных запустится

### Шаг 4: Проверьте подключение через веб-интерфейс

1. Откройте: `https://tracy-api.onrender.com/health`
   - Должно вернуться: `{"status": "ok", "timestamp": "..."}`
2. Если health check работает, но `/api/events` не работает - проблема в базе данных

### Шаг 5: Пересоздайте базу данных (если ничего не помогает)

1. В Render.com удалите старую базу данных
2. Создайте новую базу данных PostgreSQL
3. Скопируйте новый **Internal Database URL**
4. Обновите `DATABASE_URL` в Web Service
5. Перезапустите Web Service

## Что должно быть в логах при успешном запуске:

```
Используется PostgreSQL
🚀 Запуск API сервера на порту 10000
```

Если в логах есть ошибки - пришлите их, и я помогу исправить!
