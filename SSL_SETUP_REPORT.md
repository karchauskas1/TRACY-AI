Проверка DNS через Google DNS (8.8.8.8) не вернула результатов, что означает:
- DNS A-запись для домена не настроена
- Или DNS еще не распространился (если только что настроили)

**Я НЕ МОГУ настроить DNS программно**, так как:
- DNS записи настраиваются через панель управления доменом у регистратора
- Для этого требуется доступ к учетной записи регистратора домена (Namecheap, GoDaddy, Cloudflare и т.д.)
- У меня нет доступа к этой панели

## 📋 Что нужно сделать

### 1. Настроить DNS A-запись (выполните самостоятельно)

1. Войдите в панель управления доменом у вашего регистратора
2. Найдите раздел **DNS Management** / **DNS Records** / **Управление DNS**
3. Добавьте или отредактируйте **A-запись**:
   - **Имя/Name**: `@` или оставьте пустым (для корневого домена)
   - **Тип/Type**: `A`
   - **Значение/Value/IP**: `5.35.126.42`
   - **TTL**: `3600` (или оставьте по умолчанию)
4. Сохраните изменения
5. Подождите распространения DNS (обычно 5-30 минут, до 24 часов)

### 2. Проверить DNS (после настройки)

```bash
# На вашем компьютере (Mac)
dig yourbody.com +short
# Ожидаемый результат: 5.35.126.42

# Или через онлайн-сервис
# Откройте в браузере: https://dnschecker.org/
# Введите: yourbody.com
# Выберите тип: A
# Должен вернуться IP: 5.35.126.42
```

### 3. Установить SSL сертификат (после настройки DNS)

**Вариант A: Автоматический скрипт**

Я создал скрипт `setup_ssl.sh`, который автоматически:
- Проверит DNS
- Установит SSL сертификат через certbot
- Настроит nginx для использования SSL
- Настроит редирект HTTP → HTTPS

```bash
# На сервере
ssh root@5.35.126.42
bash setup_ssl.sh
```

**Вариант B: Ручная установка**

```bash
# Подключитесь к серверу
ssh root@5.35.126.42

# Установите SSL сертификат через certbot
certbot --nginx -d yourbody.com \
    --non-interactive \
    --agree-tos \
    --email ваш_email@example.com \
    --redirect

# Проверьте конфигурацию nginx
nginx -t

# Перезагрузите nginx
systemctl reload nginx

# Проверьте сертификат
certbot certificates
```

**Важно**: Замените `ваш_email@example.com` на ваш реальный email адрес.

## ✅ После установки SSL

После успешной установки SSL:
- API будет доступен по HTTPS: `https://yourbody.com/api/...`
- Веб-приложение сможет обращаться к API без ошибок Mixed Content Policy
- Все HTTP запросы будут автоматически перенаправляться на HTTPS
- SSL сертификат будет автоматически обновляться каждые 60 дней

## 📞 Где найти панель управления DNS?

Панель управления DNS находится у регистратора домена. Распространенные регистраторы:

- **Namecheap**: https://www.namecheap.com/ → My Account → Domain List → Manage → Advanced DNS
- **GoDaddy**: https://www.godaddy.com/ → My Products → DNS
- **Cloudflare**: https://dash.cloudflare.com/ → DNS → Records
- **Reg.ru**: https://www.reg.ru/ → Личный кабинет → Домены → DNS-серверы и зона
- **Timeweb**: https://timeweb.com/ → Домены → Управление DNS
