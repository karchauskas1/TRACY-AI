## Диагностика

### Возможные причины проблемы:
1. **Next.js router race condition**: `router.push` мог вызываться до полной инициализации
   - **Решение**: Добавлены `setTimeout` перед навигацией
2. **Обёртка Link блокировала события**: Вложенные интерактивные элементы
   - **Решение**: Заменены на `onClick` обработчики
3. **Кэш браузера**: Старая версия приложения
   - **Решение**: Hard refresh (Cmd+Shift+R / Ctrl+Shift+F5)
